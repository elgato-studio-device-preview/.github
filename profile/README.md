## Fast Device Preview Brief

What is Elgato Studio? Elgato's desktop app for compatible capture cards, cameras and prompters.  
Why use it for Device Preview? See the card's HDMI feed and check signal and audio before committing to a take.  
Who needs it? Console creators who want clean footage without building a full broadcast scene.  
Does it support Windows on Arm? Yes, there is an Arm64 build, but verify the exact capture card separately.  

## Device Preview Overview

This independent guide focuses on Elgato Studio's capture workspace. Use it to choose the card, see the incoming feed and record straight to disk. A working desktop preview and a working HDMI passthrough picture are separate checks.

Elgato lists HD60 X, HD60 S+, Game Capture Neo and 4K X in both its Studio capture lineup and Windows on Arm hardware table. Studio also lists 4K S, but check its own system requirements before picking it for an Arm machine. Keep the PCIe 4K Pro, 4K60 Pro and 4K60 Pro MK.2 on supported x64 Windows systems; the existence of an Arm build or a Mac build does not make those cards compatible with it. Do not substitute the original HD60 S or HD60 Pro for the similarly named Studio models.

The capture app is one layer and the card is another; the prompter feature is an optional add-on. Read reports for your exact model and USB or PCIe connection rather than assuming the same experience across the lineup. Compare a general-purpose mixer for scene-based streaming, or the legacy 4K Capture Utility for certain cards missing from Studio's list.

## Getting Started Playbook

Read the model label, not just the name on the box, then match it to Elgato's capture compatibility notes. Check System Type before choosing the Windows x64 or Arm64 build, or compare your macOS version with the selected release notes. Allow camera and microphone permissions if the app prompts for them.

Plug the console into HDMI In and connect HDMI Out to the play display if using passthrough. For a USB card, use a direct port and a cable rated for the card rather than starting through a hub. Select the card, verify the picture and meters, then play back a short test from the recording location.

## Everyday Use

In the app, pick the device you actually intend to record before changing features such as preview volume or the save location. Routine capture does not use the prompter login; that sign-in belongs to the optional add-on. Review audio and color in a saved file, since a good-looking preview alone does not validate the export.

## Troubleshooting Common Issues

Install issues? Check the Windows architecture or macOS version against the installer you selected.  
Performance problems? Try a lower capture mode and test a direct USB port before replacing the card.  
Edition differences? Basic capture runs without a sign-in; use an account only where a feature such as the prompter requires it.  
Compatibility? Check the full card model, its OS support, and whether another app already has the device open.  
Update failures? Check the stable release notes and retry the install rather than changing firmware at the same time.
